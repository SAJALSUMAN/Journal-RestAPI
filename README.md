# 📓 Journal REST API

A RESTful API built with **Spring Boot** to manage personal journal entries.  
It allows users to create, read, update, and delete journal entries efficiently, with **MongoDB** as the database.

---

## 🚀 Features
- ✍️ **Create** journal entries  
- 📖 **Read** all or single entries  
- ✏️ **Update** existing entries  
- 🗑️ **Delete** entries  
- 🌐 RESTful architecture  
- 💾 MongoDB integration  

---

## 🛠️ Tech Stack
- **Java 17+**
- **Spring Boot** (REST API, Spring Data MongoDB)
- **MongoDB**
- **Maven**
